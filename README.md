# O_Shop

Online store backend pet project, in progress.

Product catalog, user accounts, shopping cart, admin panel.
WARNING: 
!!!Don't upload to HOSTING! If you want, you'll need to change the files slightly, the keys and database are open.
WARNING

## Run locally

```powershell
cd D:\MyProjects\O_Shop
.\start.ps1
```

Open:
- API: `http://localhost:8000`
- Swagger: `http://localhost:8000/docs`
- Admin: `http://localhost:5000/admin/login`
- Frontend: `http://localhost:5500/index.html`

## Stop locally

```powershell
cd D:\MyProjects\O_Shop
.\stop.ps1
```
